# Цель работы

Подобрать параметры экспоненциальной модели затухания по измерениям методом наименьших квадратов и оценить
качество подгонки.

# Ход работы

## Модель

Измеряемая величина описывается моделью [](#eq:model) с тремя параметрами: амплитудой $a$, скоростью затухания $k$
и фоном $c$.

$$ y(x) = a\,e^{-k x} + c $$ {#eq:model}

::: where
$y$
:   измеряемая величина

$x$
:   время, с
:::

## Данные

Выполнено []{var=n} измерений на отрезке от []{var=x_min format=".1f"} до []{var=x_max format=".1f"} с.
Первые строки данных приведены в таблице [](#tbl:data).

::: {.insert name=data_table}
:::
