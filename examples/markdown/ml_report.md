# Цель работы

Сравнить три модели регрессии (линейную, гребневую и случайный лес) на наборе данных *diabetes* по метрикам
MSE, MAE и $R^2$ и проверить, значимо ли различие между лучшими из них.

# Ход работы

## Постановка

В наборе []{var=n_total} наблюдений и []{var=n_features} признаков. Данные разделены на обучающую
([]{var=n_train} наблюдений) и тестовую ([]{var=n_test}) выборки. Качество моделей оценено по формулам
[](#eq:mse) и [](#eq:r2).

$$ \mathrm{MSE}=\frac{1}{n}\sum_{i=1}^{n}\left(y_i-\hat y_i\right)^2 $$ {#eq:mse}

::: where
$y_i$
:   фактическое значение

$\hat y_i$
:   прогноз модели

$n$
:   размер тестовой выборки
:::

$$ R^2=1-\frac{\sum_i (y_i-\hat y_i)^2}{\sum_i (y_i-\bar y)^2} $$ {#eq:r2}

::: where
$\bar y$
:   среднее фактических значений
:::

Обучение и оценка моделей выполнены функцией из листинга [](#lst:fit).
